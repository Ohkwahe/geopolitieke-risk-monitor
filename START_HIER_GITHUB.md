# Update van v1.4.0 naar v1.4.1

1. Download het ZIP-pakket via de HTML-installer en pak uit.
2. Upload gewijzigde bestanden naar je bestaande GitHub repository.
3. Commit op main. Het nieuwsbestand `data/auto-news.json` is niet inbegrepen en blijft behouden.
4. Ververs eerst de GitHub Pages-website in Safari, open daarna de iPhone-app.
5. Test de drie tegels en ‘↑ Boven’.

GitHub Actions nieuwsverwerking hoeft voor deze zuivere UI-correctie niet handmatig gestart te worden.
