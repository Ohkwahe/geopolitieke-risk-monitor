# Risk Monitor v3.0.1 – Speech Fix

Deze correctierelease herstelt de voorleesbediening en geeft diagnoseinformatie op de iPhone.

## Installeren
1. Maak via de HTML-installer het ZIP-pakket.
2. Upload de inhoud naar de bestaande GitHub Pages-repository, branch `main`.
3. Update ten minste `index.html`, `sw.js`, en `BUILDINFO.json`.
4. Geen handmatige nieuwsworkflow nodig: de nieuwsverwerking is niet gewijzigd.
5. Herlaad in Safari, open de beginscherm-app opnieuw; controleer versie v3.0.1.

## Geluidstest
1. Open Instellingen → **Voorlezen testen en geluid oplossen**.
2. Tik op **Test voorleesstem** en controleer hoorbaar geluid.
3. Zie je **Stem speelt af** maar hoor je niets? Controleer mediavolume en audio-uitvoer.
4. Zie je een foutmelding? Noteer de foutcode.
5. Test bij problemen de GitHub Pages-website rechtstreeks in Safari; iOS-PWA en Safari kunnen verschillend reageren.

Bij onvoldoende ondersteuning van de iOS-spraakfunctie kan de native iOS-voorleesfunctie via Toegankelijkheid als alternatief dienen.
