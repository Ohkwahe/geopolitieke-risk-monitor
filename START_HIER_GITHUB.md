# Upgrade via GitHub
1. Open HTML-installer in Firefox en download ZIP.
2. Pak ZIP uit; upload alle bestanden naar bestaande repository op main. Ook de scripts-map moet vervangen worden.
3. Laat data/auto-news.json ongemoeid.
4. Start in Actions de bestaande Risk Monitor-workflow eenmaal handmatig.
5. Controleer groen resultaat en open daarna de website eerst in Safari, herlaad, vervolgens de iPhone-app.
6. Kijk of v1.5.0 verschijnt, nieuws in Nederlands, Belgische indicator op kaarten en detailweergave.
7. Geef pas GO na succesvolle echte GitHub-run en iPhone-test.
