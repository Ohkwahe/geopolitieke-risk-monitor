Instellingen & werkwijze

v1.2.0

Nieuwsaanvoer

GitHub Actions controleert nieuwsfeeds rond 08:10 en 18:10 Belgische tijd. Nieuwe gegevens verschijnen hier bij het openen of verversen van de app. Werkelijke uitvoeringstijd kan afwijken.

Score (0–14)

Militaire escalatie 0–4, mogelijke Belgische impact 0–4, nieuwheid 0–3, bronbetrouwbaarheid 0–3. 10–14 = belangrijk signaal; 7–9 = nog te beoordelen; 0–6 = onder drempel. Een enkele nieuwsbron blijft normaal onder de drempel. Dit is geen voorspellend model.

Belangrijke beperking

Deze gratis versie maakt een eerste selectie met vaste regels. Er is geen volwaardige AI-analyse, onafhankelijke factcheck of automatische overdracht van je ChatGPT-beoordelingen. Voor die laatste koppeling is een afzonderlijke AI-/serverintegratie nodig. De rubrieken blijven wél automatisch bijgewerkt met nieuwe RSS-signalen.

Handmatige ChatGPT-analyses (optioneel)

Voor reeds beoordeelde berichten kun je JSON importeren. Voer geen HTML of Markdown in. Opgeslagen gegevens blijven op dit toestel. Dit is niet nodig voor de automatische nieuwsfeed.
