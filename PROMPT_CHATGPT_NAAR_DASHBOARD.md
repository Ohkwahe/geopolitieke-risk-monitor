# ChatGPT-update omzetten naar dashboard-import

In de mobiele app: **Beheer → Kopieer ChatGPT-importprompt**. Plak de prompt als antwoord op je recentste geopolitieke update in ChatGPT. ChatGPT zet de melding dan om naar het JSON-formaat van het dashboard.

Kopieer het verkregen JSON-object, ga naar de app, kies **Beheer → JSON plakken → Update importeren**.

> Belangrijk: dit is een handmatige overbrenging. De app controleert de claims of bronlinks niet zelfstandig. De prompt laat ChatGPT om verduidelijking vragen bij ontbrekende scores of datums; vermijd fictieve precisie.

De bestaande automatische ChatGPT-alert om 08:00 en 18:00 verandert niet. Een automatische JSON-synchronisatie vergt een latere aparte integratie.
